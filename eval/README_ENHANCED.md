# 增强版多智能体系统实验框架

## 🚀 概述

这是一个增强版的多智能体系统实验框架，专门设计用于生成符合顶级论文要求的实验结果和可视化分析。该框架包含丰富的测试数据、多种实验配置和学术级可视化功能。

## ✨ 主要特性

### 1. 丰富的实验数据
- **16个多样化测试查询**：涵盖机器学习、深度学习、NLP、计算机视觉等多个AI领域
- **多复杂度级别**：基础、中级、高级三个难度等级
- **多种查询类型**：知识查询、解释、比较、教程、分析、实现、优化、设计、评估、应用、趋势分析、影响分析、创新、伦理讨论、预测等
- **智能领域识别**：自动识别查询所属的AI子领域
- **关键词提取**：自动提取查询的关键词和元数据

### 2. 多种实验配置
- **基础配置**：双智能体系统（查询解释器 + 执行器）
- **标准配置**：三智能体系统（查询解释器 + 知识检索器 + 执行器）
- **增强配置**：增强版多智能体系统
- **专家配置**：专家级深度分析配置

### 3. 学术级可视化
- **高质量图表**：300 DPI，符合学术论文标准
- **专业配色方案**：使用学术级配色，确保图表清晰易读
- **多种图表类型**：箱线图、条形图、雷达图、热力图、散点图、直方图
- **双语标签**：支持中英文标签，适合国际学术发表
- **LaTeX表格**：自动生成LaTeX格式的性能汇总表

## 🛠️ 安装和设置

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 确保智能体模块可用
确保 `src/` 目录中的智能体模块可以正常导入。

## 📊 使用方法

### 1. 运行实验
```bash
python working_experiment.py
```

这将：
- 生成16个多样化测试查询
- 使用4种不同配置运行实验
- 计算质量评分和统计信息
- 保存结果到 `results/` 目录

### 2. 生成可视化图表
```bash
python visualization.py
```

这将：
- 自动加载最新的实验结果
- 生成6种学术级可视化图表
- 创建LaTeX格式的性能表格
- 输出详细的统计报告

### 3. 测试框架功能
```bash
python test_enhanced_framework.py
```

这将验证：
- 实验框架的基本功能
- 测试查询生成
- 实验配置设置
- 可视化模块导入

## 📋 输出文件

### LaTeX表格文件
- 标准学术格式

## 🔧 自定义配置

### 修改测试查询
在 `working_experiment.py` 中编辑 `_generate_test_queries()` 方法。

### 调整实验配置
在 `working_experiment.py` 中编辑 `_generate_experiment_configs()` 方法。

### 自定义可视化样式
在 `visualization.py` 中修改 `ACADEMIC_COLORS` 和 `ACADEMIC_STYLE` 常量。
