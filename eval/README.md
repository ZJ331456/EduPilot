# 多智能体系统实验框架

## 概述

本实验框架用于对比分析多智能体教育系统与传统方法的性能差异，包括：

- **完整多智能体系统**：8个智能体协作
- **核心智能体系统**：仅核心智能体
- **传统RAG系统**：传统检索增强生成

## 文件结构

```
eval/
├── simple_experiment.py      # 简化实验运行器
├── experiment_framework.py   # 完整实验框架
├── visualization.py          # 结果可视化分析
├── requirements.txt          # Python依赖包
├── README.md                # 本说明文档
└── results/                 # 实验结果目录（自动创建）
```

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行实验

```bash
python simple_experiment.py
```

### 3. 查看可视化结果

```bash
python visualization.py
```

## 实验设计

### 测试查询集
- **Q001**: 什么是机器学习？(基础概念)
- **Q002**: 深度学习与传统机器学习的区别？(对比分析)
- **Q003**: 如何设计神经网络解决图像分类？(问题解决)
- **Q004**: 强化学习在游戏AI中的应用原理？(应用原理)
- **Q005**: 注意力机制如何工作？(技术细节)

### 用户画像
- **U001**: 初学者，计算机科学学生
- **U002**: 中级用户，数据科学家
- **U003**: 高级用户，研究科学家

### 评估指标
- **准确性** (30%): 答案正确性
- **完整性** (25%): 内容覆盖度
- **解释质量** (25%): 结构化程度
- **学习价值** (20%): 教育价值

## 统计分析

### 描述性统计
- 平均值、标准差
- 最小值、最大值
- 样本数量

### 对比分析
- t检验
- Mann-Whitney U检验
- 效应量 (Cohen's d)

### 效应量解释
- |d| < 0.2: 可忽略
- |d| < 0.5: 小效应
- |d| < 0.8: 中等效应
- |d| ≥ 0.8: 大效应

## 预期结果

基于理论分析，预期结果应该显示：

1. **质量评分**: 完整多智能体系统 > 核心系统 > 传统RAG
2. **响应时间**: 传统RAG < 核心系统 < 完整多智能体系统
3. **统计显著性**: 系统间差异应达到中等或大效应量
4. **综合性能**: 完整多智能体系统在质量与效率平衡上最优

## 自定义配置

### 修改测试查询
编辑 `simple_experiment.py` 中的 `_generate_test_queries()` 方法

### 调整用户画像
修改 `_generate_user_profiles()` 方法

### 更改评估权重
在 `_define_metrics()` 中调整各指标权重

## 故障排除

### 常见问题
1. **导入错误**: 确保安装了所有依赖包
2. **内存不足**: 减少测试查询数量或用户画像数量
3. **图表显示问题**: 检查matplotlib后端配置

### 调试模式
在脚本中添加更多print语句来跟踪执行流程

## 扩展功能

### 添加新系统
1. 在 `_initialize_systems()` 中添加新系统
2. 在 `simulate_system_response()` 中添加响应逻辑
3. 更新相关统计和可视化代码

### 新评估指标
1. 在 `_define_metrics()` 中定义新指标
2. 在 `_evaluate_response_quality()` 中实现评估逻辑
3. 更新综合评分计算
