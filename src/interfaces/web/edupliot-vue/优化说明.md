# EduPilot Vue 项目优化说明

## 优化概述

本次优化聚焦于代码组织、性能提升、用户体验改进和代码质量提升，不添加新功能，而是优化现有逻辑和布局。

## 主要优化内容

### 1. 代码组织优化 ✨

#### 创建统一的工具函数库
- **`utils/format.js`** - 格式化工具函数
  - `formatDate()` - 统一的日期格式化（支持多种格式）
  - `formatPercentage()` - 百分比格式化
  - `formatNumber()` - 数字千分位格式化
  - `formatFileSize()` - 文件大小格式化
  - `formatDuration()` - 时间持续格式化
  - `truncateText()` - 文本截断

- **`utils/constants.js`** - 全局常量配置
  - 情感类型/颜色/标签映射
  - 趋势类型映射
  - 学习模式映射
  - API配置（超时、重试等）
  - 消息配置（显示时长）
  - 动画配置
  - 本地存储键名
  - 响应式断点
  - 防抖/节流延迟配置

- **`utils/validators.js`** - 数据验证工具
  - `isEmpty()` - 空值检测
  - `isValidNumber()` - 数字验证
  - `isValidDate()` - 日期验证
  - `isValidObject()` - 对象验证
  - `safeGet()` - 安全获取嵌套属性
  - `cleanObject()` - 清理对象空值

- **`utils/errorHandler.js`** - 统一错误处理
  - `getErrorMessage()` - 提取友好的错误消息
  - `showError/Success/Warning/Info()` - 统一的消息提示
  - `handleApiError()` - API错误处理
  - `withErrorHandler()` - 错误处理包装器
  - `withRetry()` - 重试机制包装器

- **`utils/mappers.js`** - 数据映射转换
  - 情感/趋势/模式翻译函数
  - 图表数据转换（节点/边）
  - 用户画像数据规范化
  - 学习记录数据规范化

- **`utils/index.js`** - 统一导出所有工具函数

## 使用指南

### 工具函数使用示例

```javascript
// 1. 格式化相关
import { formatDate, formatPercentage, formatNumber } from '@/utils'

// 格式化日期
formatDate(timestamp, 'full')     // 完整日期时间
formatDate(timestamp, 'date')     // 仅日期
formatDate(timestamp, 'time')     // 仅时间
formatDate(timestamp, 'relative') // 相对时间（5分钟前）

// 格式化百分比
formatPercentage(0.8567)          // "85.7%"
formatPercentage(0.8567, 0)       // "86%"

// 格式化数字
formatNumber(1234567)             // "1,234,567"

// 2. 验证相关
import { isEmpty, isValidNumber, safeGet } from '@/utils'

// 检查空值
isEmpty(null)                     // true
isEmpty('')                       // true
isEmpty([])                       // true

// 安全获取属性
safeGet(obj, 'user.profile.name', 'Unknown')

// 3. 错误处理相关
import { showError, showSuccess, handleApiError } from '@/utils'

// 显示消息
showSuccess('操作成功')
showError(error, '操作失败')

// 处理API错误
try {
  const data = await api.someMethod()
} catch (error) {
  handleApiError(error, {
    defaultMessage: '加载失败',
    showMessage: true
  })
}

// 4. 映射相关
import { translateEmotion, getEmotionColor } from '@/utils'

// 翻译情感
translateEmotion('positive')      // "积极"

// 获取颜色
getEmotionColor('positive')       // "#67C23A"
```

### 常量使用示例

```javascript
import {

const debouncedFn = useDebounceFn(fn, DEBOUNCE_DELAYS.SEARCH)
```
