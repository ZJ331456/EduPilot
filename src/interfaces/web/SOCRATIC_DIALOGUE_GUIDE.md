# 苏格拉底式对话触发指南

## 🎯 什么是苏格拉底式对话？

苏格拉底式对话是一种通过提问来引导学习者深入思考的教学方法。EduPilot 的苏格拉底式对话功能会：

- 通过精心设计的问题引导你思考
- 帮助你发现知识之间的内在联系
- 培养批判性思维和深度理解能力
- 根据你的理解水平调整引导策略

## 🚀 如何触发苏格拉底式对话？

### 方法1：使用苏格拉底式问题模板

1. **切换到苏格拉底模式**
   - 在侧边栏的"快速示例"卡片中
   - 点击右上角的"苏格拉底模式"按钮
   - 界面会切换到苏格拉底式问题列表

2. **选择触发问题**
   - 选择以下类型的问题更容易触发苏格拉底式对话：
     - "我不太理解这个概念，能帮我分析一下吗？"
     - "请引导我一步步理解这个历史事件"
     - "能通过提问的方式帮助我学习吗？"
     - "请用苏格拉底式的方法来引导我思考"

### 方法2：直接请求苏格拉底式引导

在输入框中直接输入以下类型的请求：

```
- "请用苏格拉底式的方法来引导我理解这个概念"
- "我想通过对话来深入理解这个问题"
- "请帮助我建立对这个问题的全面认识"
- "能通过提问的方式帮助我学习吗？"
```

### 方法3：表达学习困难

当你在学习过程中遇到困难时，可以这样表达：

```
- "我不太理解这个概念，能帮我分析一下吗？"
- "这个问题很复杂，我需要更深入的思考"
- "我想从多个角度来理解这个问题"
- "请引导我一步步理解这个历史事件"
```

## 🔍 苏格拉底式对话的特征

当苏格拉底式对话被触发时，你会看到：

### 1. **苏格拉底式对话信息卡片**
- 显示当前苏格拉底式问题
- 问题类型（澄清类、假设类、证据类等）
- 理解水平评估
- 引导策略说明

### 2. **工作流状态更新**
- 对话阶段显示为"苏格拉底引导"
- 理解水平实时更新
- 对话轮次跟踪

### 3. **引导性问题**
- 系统会提出引导性问题
- 问题会根据你的回答调整
- 逐步深入，建立完整理解

## 💡 苏格拉底式对话的问题类型

### 1. **澄清类问题**
- 帮助你澄清概念和想法
- 例："当你使用'XX'这个词时，你心中想到的具体含义是什么？"

### 2. **假设类问题**
- 引导你发现隐含假设
- 例："在你的思考中，你是否假设了XX一定会导致YY？"

### 3. **证据类问题**
- 引导你寻找和评估证据
- 例："什么样的例子能够帮助我们理解XX的这个特点？"

### 4. **视角类问题**
- 引导你换位思考
- 例："如果站在XX的立场，他们会如何看待这个问题？"

### 5. **含义类问题**
- 引导你推演后果和影响
- 例："如果XX成立，那么对YY会产生什么影响？"

### 6. **元认知类问题**
- 引导你反思思维过程
- 例："在思考这个问题时，你经历了怎样的思维过程？"

   - 快速示例变为"苏格拉底式引导"

3. **工作流状态**
   - 实时显示对话阶段
   - 理解水平进度条
   - 苏格拉底模式指示器

## 🔄 对话流程

### 典型的苏格拉底式对话流程：

1. **触发阶段**
   - 用户提出需要引导的问题
   - 系统识别为苏格拉底式对话场景

2. **引导阶段**
   - 系统提出引导性问题
   - 用户回答并思考
   - 系统根据回答调整策略

3. **深入阶段**
   - 逐步深入核心概念
   - 建立知识联系
   - 培养批判思维

4. **总结阶段**
   - 整合理解成果
   - 提供下一步建议
   - 完成学习目标

## 🎯 最佳实践

### 如何获得最佳的苏格拉底式对话体验：

1. **诚实回答**
   - 真实表达你的理解和困惑
   - 不要担心回答错误

2. **深入思考**
   - 认真思考每个问题
   - 尝试从多个角度分析

3. **主动提问**
   - 在对话中提出自己的疑问
   - 寻求更深入的解释

4. **保持开放**
   - 接受新的观点和角度
   - 愿意调整自己的理解

## 🚨 注意事项

1. **触发条件**
   - 不是所有问题都会触发苏格拉底式对话
   - 系统会根据问题类型和用户状态判断

2. **对话长度**
   - 苏格拉底式对话通常比普通回答更长
   - 需要更多轮次的交互

3. **理解水平**
   - 系统会根据你的理解水平调整引导策略
   - 初学者会得到更多基础引导
