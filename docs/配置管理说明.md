# 配置管理说明

## 概述

多智能体学习助手系统现在使用统一的配置管理系统，所有硬编码的配置信息都集中在 `src/config/config.yaml` 文件中，支持环境变量覆盖和动态配置管理。

## 配置文件结构

### 1. 应用基础配置

```yaml
app:
  name: "多智能体学习助手"
  version: "1.0.0"
  debug: true
  host: "0.0.0.0"
  port: 8000
  workers: 4
```

### 2. 数据库配置

```yaml
database:
```

## 使用方法

### 1. 基本配置获取

```python
from config import get_config, get_config_manager

# 获取单个配置值
app_name = get_config('app.name', '默认应用名')
debug_mode = get_config('app.debug', False)

# 获取配置管理器实例
config_manager = get_config_manager()
mongodb_url = config_manager.get('database.mongodb.url')
```

### 2. 获取特定模块配置

```python
from config import (
    get_llm_config,
    get_database_config,
    get_knowledge_base_config,
    get_agent_config,
    get_multi_agent_config
)

# 获取LLM配置
llm_config = get_llm_config('ollama')
model_name = llm_config.get('default_model')

# 获取数据库配置
db_config = get_database_config()
mongodb_url = db_config['url']

# 获取知识库配置
kb_config = get_knowledge_base_config()
cache_enabled = kb_config.get('cache.enabled')

# 获取智能体配置
agent_config = get_agent_config('decision_agent')
retrieval_threshold = agent_config.get('retrieval_threshold')
```

### 3. 环境变量覆盖

配置文件支持环境变量覆盖，格式为 `${ENV_VAR_NAME}`：

```yaml
llm:
  qwen:
    api_key: "${QWEN_API_KEY}"
    base_url: "${QWEN_BASE_URL}"
```

在代码中使用：

```python
from config import get_config

# 自动从环境变量获取，如果环境变量不存在则使用配置文件中的值
api_key = get_config('llm.qwen.api_key')
```

### 4. 在智能体中使用配置

#### 修改前（硬编码）：

```python
class KnowledgeRetrieverAgent(BaseAgent):
    def __init__(self, knowledge_base_dir: str = "../concept_knowledge_bases"):
        self.knowledge_base_dir = knowledge_base_dir
        self.cache_ttl = 3600  # 硬编码
        self.max_cache_size = 1000  # 硬编码
        self._max_workers = 4  # 硬编码
```

#### 修改后（使用配置）：

```python
class KnowledgeRetrieverAgent(BaseAgent):
    def __init__(self, knowledge_base_dir: str = None):
        # 导入配置管理器
        from config import get_knowledge_base_config
        
        kb_config = get_knowledge_base_config()
        
        # 使用配置值
        self.knowledge_base_dir = knowledge_base_dir or kb_config.get('root_dir')
        
        # 缓存配置
        cache_config = kb_config.get('cache', {})
        self.cache_ttl = cache_config.get('ttl_hours', 24) * 3600
        self.max_cache_size = cache_config.get('max_size', 1000)
        
        # 检索配置
        retrieval_config = kb_config.get('retrieval', {})
        self._max_workers = retrieval_config.get('max_concurrent_queries', 4)
```

## 配置验证

```python
from config import get_config_manager

config_manager = get_config_manager()

# 验证配置
if config_manager.validate():
    print("配置验证通过")
else:
    print("配置验证失败")
```

## 动态配置更新

```python
from config import get_config_manager

config_manager = get_config_manager()

# 更新配置
config_manager.update({
    'app': {
        'debug': True,
        'port': 8080
    }
})

# 保存到文件
config_manager.save()

# 重新加载配置
config_manager.reload()
```

## 环境特定配置

配置文件支持不同环境的配置：

```yaml
environments:
  development:
    debug: true
    log_level: "DEBUG"
    database:
      url: "mongodb://localhost:27017"
  production:
    debug: false
    log_level: "WARNING"
    database:
      url: "${MONGODB_URL}"
    security:
      authentication:
        enabled: true
```

使用环境特定配置：

```python
from config import get_config_manager

config_manager = get_config_manager()
env_config = config_manager.get_environment_config('production')
```

## 最佳实践

### 1. 配置分层

- **基础配置**：应用名称、版本等
- **环境配置**：数据库连接、API密钥等
- **功能配置**：各模块的具体参数
- **性能配置**：缓存、并发等

### 2. 默认值处理

```python
# 好的做法：提供合理的默认值
cache_size = get_config('knowledge_base.cache.max_size', 1000)

# 避免的做法：不提供默认值
cache_size = get_config('knowledge_base.cache.max_size')  # 可能返回None
```

### 3. 配置验证

```python
def validate_llm_config():
    llm_config = get_llm_config()
    required_fields = ['client_name', 'timeout', 'max_retries']
    
    for field in required_fields:
        if field not in llm_config:
            raise ValueError(f"Missing required LLM config field: {field}")
```

### 4. 环境变量管理

```bash
# 开发环境
export ENVIRONMENT=development
export QWEN_API_KEY=your_dev_key

# 生产环境
export ENVIRONMENT=production
export QWEN_API_KEY=your_prod_key
export MONGODB_URL=mongodb://prod-server:27017
```

## 迁移指南

### 1. 识别硬编码配置

查找代码中的硬编码值：
- 模型名称
- 文件路径
- 超时时间
- 缓存大小
- API端点

### 2. 添加到配置文件

将硬编码值添加到 `config.yaml` 的相应部分。

### 3. 修改代码

使用配置管理器替换硬编码值：

```python
# 修改前
model_name = "qwen2.5:latest"

# 修改后
from config import get_llm_config
llm_config = get_llm_config()
model_name = llm_config.get('default_model', 'qwen2.5:latest')
```

### 4. 测试验证

确保配置更改后系统正常运行。

## 总结

通过使用统一的配置管理系统，您可以：

1. **集中管理**：所有配置信息都在一个文件中
2. **环境隔离**：不同环境使用不同配置
3. **动态更新**：运行时可以更新配置
4. **类型安全**：配置值有明确的类型和默认值
5. **易于维护**：修改配置不需要重新编译代码

这样的配置管理方式使系统更加灵活、可维护和可扩展。
