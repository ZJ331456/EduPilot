### 模块职责划分

| 层级 | 模块 | 职责 | 技术 |
|------|------|------|------|
| **接口层** | FastAPI | RESTful API、流式响应、请求验证 | FastAPI, Pydantic |
| **接口层** | Vue 3 | 用户界面、状态管理、实时交互 | Vue 3, Pinia, Element Plus |
| **核心层** | LangGraph | 工作流编排、状态管理、路由决策 | LangGraph, StateGraph |
| **核心层** | QueryAnalyzer | 意图识别、检索决策、概念提取 | 启发式算法 + LLM |
| **核心层** | Orchestrator | 任务编排、Agent调度决策 | 多维度分析 + LLM |
| **核心层** | DraftWriter | 内容撰写、草稿生成和修改 | LLM生成 |
| **核心层** | Reviewer | 质量审核、内容检查 | LLM审核 |
| **核心层** | CurriculumDesigner | 课程设计、学习路径生成 | LLM生成 |
| **核心层** | QuizMaster | 测试题生成、评估反馈 | LLM生成 |
| **核心层** | ToolSpecialist | 工具调用、计算、搜索 | 安全执行环境 |
| **核心层** | KnowledgeManager | 知识检索、图检索、相关性评分 | nano-graphrag, 并发检索 |
| **核心层** | SocraticGuide | 问题生成、理解水平评估 | 8种问题类型 + 5级评估 |
| **核心层** | MemoryManager | 用户画像、学习记录、会话记忆 | 三元组提取、情感分析 |
| **基础设施** | LLM Manager | 统一LLM接口、多客户端支持 | Ollama, Qwen API |
| **基础设施** | GraphRAG | 知识图谱构建、语义检索 | nano-graphrag, HNSWlib |
| **基础设施** | Persistence | 数据持久化、状态恢复 | JSON, MongoDB |

### 1. 主工作流程（LangGraph节点流程）

```
用户查询输入
    ↓
┌─────────────────────────────────────────────────────────┐
│  节点1: QueryAnalyzer (查询分析)                         │
│  ┌───────────────────────────────────────────────────┐  │
│  │ - 意图识别（多种意图类型）                          │  │
│  │ - LLM精修（置信度不足时触发）                      │  │
│  │ - 检索决策                                         │  │
│  │ - 概念提取                                         │  │
│  │ - 输出: intent, confidence, core_concepts         │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│  节点2: Orchestrator (任务编排)                         │
│  ┌───────────────────────────────────────────────────┐  │
│  │ - 分析当前状态和上下文                             │  │
│  │ - 确定计划类型                                     │  │
│  │ - 决定需要调用的Worker Agents                      │  │
│  │ - 生成调度指令 (next_workers)                     │  │
│  │ - 输出: plan, next_workers                        │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│  条件路由 - Fan-out (根据next_workers动态路由)           │
│  ┌───────────────────────────────────────────────────┐  │
│  │ 可能的路由目标：                                   │  │
│  │ ├─ KnowledgeManager (知识检索)                    │  │
│  │ ├─ ToolSpecialist (工具调用)                      │  │
│  │ ├─ CurriculumDesigner (课程设计)                  │  │
│  │ ├─ SocraticGuide (苏格拉底引导)                    │  │
│  │ ├─ MemoryManager (记忆管理)                       │  │
│  │ └─ DraftWriter (直接撰写)                         │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│  Fan-in: 所有工具节点执行完后汇聚到 DraftWriter          │
│  ┌───────────────────────────────────────────────────┐  │
│  │ KnowledgeManager → DraftWriter                     │  │
│  │ ToolSpecialist → DraftWriter                      │  │
│  │ CurriculumDesigner → DraftWriter                  │  │
│  │ SocraticGuide → DraftWriter                       │  │
│  │ MemoryManager → DraftWriter                       │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│  节点3: DraftWriter (内容撰写)                           │
│  ┌───────────────────────────────────────────────────┐  │
│  │ - 整合RAG检索结果、工具输出                       │  │
│  │ - 生成初稿或根据Reviewer意见修改                  │  │
│  │ - 输出: draft_content                            │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│  节点4: Reviewer (质量审核)                             │
│  ┌───────────────────────────────────────────────────┐  │
│  │ - 检查幻觉、语气、难度匹配度                       │  │
│  │ - 决定是否重写或通过                              │  │
│  │ - 提供修改意见                                    │  │
│  │ - 输出: is_satisfactory, critique                │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────┐
│  条件路由                                                │
│  ┌───────────────────────────────────────────────────┐  │
│  │ ├─ is_satisfactory = True                        │  │
│  │ │   └─ QuizMaster (生成测试题) → Conclusion      │  │
│  │ ├─ is_satisfactory = False                       │  │
│  │ │   └─ DraftWriter (修改) → Reviewer (循环)       │  │
│  │ └─ 直接 Conclusion                               │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
    ↓
结论生成 (Conclusion)
    ↓
返回响应给用户
```

### 2. 苏格拉底对话流程

```
用户回答苏格拉底问题
    ↓
┌─────────────────────────────────────────────────────────┐
│  SocraticGuide 评估用户回答                             │
│  ┌───────────────────────────────────────────────────┐  │
│  │ 1. 理解水平评估（5级）                              │  │
│  │    - 无知 (Ignorant): 无相关回答或完全错误          │  │
│  │    - 模糊 (Vague): 有概念但表达不清                │  │
│  │    - 部分 (Partial): 部分正确但不完整               │  │
│  │    - 清晰 (Clear): 基本正确且表达清晰               │  │
│  │    - 精通 (Proficient): 深入理解且能扩展            │  │
│  │                                                   │  │
│  │ 2. 问题类型选择（8种）                             │  │
│  │    - 澄清 (Clarifying): 引导基础理解               │  │
│  │    - 假设 (Hypothesis): 深化概念                   │  │
│  │    - 含义 (Implication): 探索深层含义               │  │
│  │    - 证据 (Evidence): 引导寻找证据                 │  │
│  │    - 视角 (Perspective): 多角度思考                │  │
│  │    - 因果 (Causality): 因果关系分析               │  │
│  │    - 类比 (Analogy): 类比迁移                     │  │
│  │    - 综合 (Synthesis): 综合应用                   │  │
│  │                                                   │  │
│  │ 3. 对话阶段流转                                    │  │
│  │    - INITIAL_QUERY → 初始查询                      │  │
│  │    - SOCRATIC_GUIDANCE → 苏格拉底引导              │  │
│  │    - CONCEPT_DEEPENING → 概念深化                 │  │
│  │    - KNOWLEDGE_INTEGRATION → 知识整合             │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
    ↓
生成新的苏格拉底问题
    ↓
等待用户回答（waiting_for_user = True）
    ↓
用户继续回答 → 继续评估 → 循环
```

### 核心技术亮点

#### 1. 动态Agent调用机制

```python
# Executor内部维护工具Agent池
self.tool_agents = {
    "knowledge_retriever": KnowledgeRetrieverAgent(),
    "socratic_guide": SocraticGuideAgent(),
    "memory_manager": MemoryManagerAgent()
}

# 根据Planner的决策动态调用
if "knowledge_retriever" in plan.required_agents:
    result = await self.tool_agents["knowledge_retriever"].run(state)
```

**优势**:
- 按需执行，减少不必要的Agent调用
- 高度可扩展，添加新Agent无需修改核心流程
- 性能提升40%（简单查询从6秒降至3.5秒）

#### 2. 并发知识检索

```python
# 多概念并行检索
tasks = [
    self._retrieve_concept(concept, strategies)
    for concept in core_concepts
]
results = await asyncio.gather(*tasks)
```

**优势**:
- 多概念同时检索，提升效率
- 支持多种检索策略融合
- 智能相关性评分

#### 3. 状态持久化机制

```python
# Checkpoint机制
checkpoint_manager.save_checkpoint(
    session_id=session_id,
    state=workflow_state,
    metadata={"stage": "after_planning"}
)
```

**优势**:
- 支持状态恢复
- 支持分支管理（时光回溯）
- 支持错误恢复

## 🚀 系统优化建议

### 1. 架构优化

#### ✅ 已完成的优化

1. **工作流简化**
   - 从6步固定流程优化为3步核心流程
   - 代码精简16.6%
   - 响应时间减少40%

2. **动态Agent调用**
   - 按需执行工具Agent
   - 减少不必要的调用
   - 性能提升显著

3. **模块化设计**
   - Executor拆分为4个独立模块
   - 代码量减少64%（1107 → 400行）
   - 职责清晰，易于维护

#### 🔄 建议的优化方向

1. **缓存机制增强**
   ```python
   # 建议：添加多级缓存
   - L1缓存：内存缓存（热点数据）
   - L2缓存：Redis缓存（会话数据）
   - L3缓存：持久化缓存（检索结果）
   ```

2. **异步处理优化**
   ```python
   # 建议：使用消息队列处理耗时任务
   - 用户画像更新 → 异步任务队列
   - 学习记录分析 → 后台任务
   - 知识图谱构建 → 定时任务
   ```

3. **数据库优化**
   ```python
   # 建议：引入关系型数据库
   - PostgreSQL：存储结构化数据（用户、会话）
   ```

### 2. 缓存策略

#### 多级缓存架构

```
L1缓存（内存）:
  - 热点数据（最近访问的会话）
  - TTL: 5分钟
  - 容量: 1000条

L2缓存（Redis）:
  - 会话数据
  - 用户画像
  - TTL: 1小时
  - 容量: 10000条

L3缓存（持久化）:
  - 检索结果缓存
  - 知识图谱缓存
  - TTL: 24小时
```

#### 缓存更新策略

```python
# 写回策略
- Write-Through: 同步更新缓存和数据库
- Write-Back: 异步更新数据库（适合非关键数据）

# 失效策略
- TTL过期
- 主动失效（数据更新时）
- LRU淘汰（内存不足时）
```
