# 多智能体学习助手 - 部署说明

## 环境要求

- Python 3.8+
- Docker & Docker Compose
- 8GB+ RAM（推荐）
- 10GB+ 磁盘空间

## 快速部署

### 1. 克隆项目

```bash
git clone <your-repository-url>
cd hw_agent
```

### 2. 安装Python依赖

```bash
pip install -r requirements.txt
```

### 3. 启动MongoDB

#### 方法一：使用Docker Compose（推荐）

```bash
# 启动MongoDB和MongoDB Express管理界面
docker-compose up -d

# 验证服务状态
docker-compose ps
```

#### 方法二：直接使用Docker命令

```bash
# 拉取MongoDB镜像
docker pull mongo:latest

# 运行MongoDB容器
docker run -d -p 27017:27017 --name mongo mongo:latest

# 验证容器状态
docker ps
```

### 4. 配置环境变量

创建 `.env` 文件：

```bash
# 数据库配置
MONGODB_URL=mongodb://localhost:27017/hw_agent
MONGODB_USERNAME=admin
MONGODB_PASSWORD=password

# 应用配置
APP_HOST=0.0.0.0
APP_PORT=8000
DEBUG=True

# 日志配置
LOG_LEVEL=INFO
LOG_FILE=logs/hw_agent.log
```

### 5. 启动应用

```bash
# 开发模式
python -m uvicorn src.app:app --host 0.0.0.0 --port 8000 --reload

# 生产模式
python -m uvicorn src.app:app --host 0.0.0.0 --port 8000 --workers 4
```

## 服务访问

- **API服务**: http://localhost:8000
- **API文档**: http://localhost:8000/docs
- **MongoDB管理界面**: http://localhost:8081 (如果使用Docker Compose)

## 数据管理

### 备份数据

```bash
# 备份MongoDB数据
docker exec mongo mongodump --out /data/backup/$(date +%Y%m%d_%H%M%S)

# 从容器复制备份文件到主机
docker cp mongo:/data/backup ./backup
```

### 恢复数据

```bash
# 恢复MongoDB数据
docker exec -i mongo mongorestore --drop /data/backup/20241201_120000/
```

## 生产环境部署

### 1. 使用Nginx反向代理

创建 `nginx.conf`:

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 2. 使用Systemd管理服务

创建 `/etc/systemd/system/hw-agent.service`:

```ini
[Unit]
Description=HW Agent Multi-Agent Learning Assistant
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/path/to/hw_agent
Environment=PATH=/path/to/venv/bin
ExecStart=/path/to/venv/bin/python -m uvicorn src.app:app --host 0.0.0.0 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
sudo systemctl enable hw-agent
sudo systemctl start hw-agent
sudo systemctl status hw-agent
```

## 故障排除

### 常见问题

1. **MongoDB连接失败**
   ```bash
   # 检查MongoDB容器状态
   docker ps | grep mongo
   
   # 重启MongoDB容器
   docker restart mongo
   ```

2. **端口被占用**
   ```bash
   # 查看端口占用
   netstat -tulpn | grep 27017
   
   # 修改端口映射
   docker run -d -p 27018:27017 --name mongo mongo:latest
   ```

3. **权限问题**
   ```bash
   # 修改数据目录权限
   sudo chown -R 999:999 ./data
   ```

## 安全建议

1. **修改默认密码**
   ```bash
   # 在docker-compose.yml中修改密码
   environment:
     - MONGO_INITDB_ROOT_PASSWORD=your_secure_password
   ```

2. **启用认证**
   ```bash
   # 在应用配置中启用MongoDB认证
   MONGODB_URL=mongodb://username:password@localhost:27017/hw_agent
   ```

3. **防火墙配置**
   ```bash
   # 只允许必要端口
   sudo ufw allow 8000
   sudo ufw allow 27017
   ```
