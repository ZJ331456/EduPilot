## 🏗️ 核心架构

### 应用初始化

**入口文件**: `src/main.js`

```javascript
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import piniaPluginPersistedstate from 'pinia-plugin-persistedstate'
import ElementPlus from 'element-plus'
import App from './App.vue'
import router from './router'

const app = createApp(App)

// 配置Pinia并添加持久化插件
const pinia = createPinia()
pinia.use(piniaPluginPersistedstate)

// 注册插件
app.use(pinia)
app.use(router)
app.use(ElementPlus)

// 注册图标
import * as ElementPlusIconsVue from '@element-plus/icons-vue'
for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component)
}

app.mount('#app')
```

## 📦 状态管理

### Pinia Store结构

#### 1. ChatStore (`stores/chat.js`)

**状态**:
```javascript
{
  messages: [],              // 消息列表
  isLoading: false,          // 加载状态
  sessionId: null,           // 会话ID
  userId: 'anonymous',       // 用户ID
  workflowState: {           // 工作流状态
    complete: false,
    waiting_for_user: false,
    conversation_stage: null,
    understanding_level: null,
    analysis: null,
    plan: null
  },
  socraticDialogue: null,    // 苏格拉底对话
  nextSuggestions: [],       // 下一步建议
  thoughtProcess: null       // 思考过程（新增）
}
```

**Actions**:
```javascript
addMessage(message)          // 添加消息
clearMessages()             // 清空消息
setLoading(loading)         // 设置加载状态
updateWorkflowState(state)  // 更新工作流状态
setSocraticDialogue(dialogue) // 设置苏格拉底对话
setThoughtProcess(process)   // 设置思考过程（新增）
clearSession()              // 清空会话（新增）
```

**状态持久化**:
- 使用 `pinia-plugin-persistedstate` 自动持久化
- 持久化字段: `messages`, `sessionId`, `workflowState`, `socraticDialogue`
- 自动限制: 只持久化最近50条消息，避免localStorage过大
- 刷新浏览器后自动恢复会话状态

## 🌐 API集成

### API客户端配置

**基础配置**: `src/api/client.js`

```javascript
import axios from 'axios'

const client = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL || 'http://localhost:8000/api/agent/v1',
  timeout: 30000,
  headers: {
    'Content-Type': 'application/json'
  }
})

// 请求拦截器
client.interceptors.request.use(config => {
  // 添加认证token等
  return config
})

// 响应拦截器
client.interceptors.response.use(
  response => response.data,
  error => {
    // 错误处理
    return Promise.reject(error)
  }
)

export default client
```

### API模块

#### 1. Workflow API (`api/workflow.js`)

```javascript
export default {
  // 启动会话
  startSession(data) {
    return client.post('/workflow/session/start', data)
  },
  
  // 继续会话
  continueSession(data) {
    return client.post('/workflow/session/continue', data)
  },
  
  // 获取会话信息
  getSession(sessionId) {
    return client.get(`/workflow/session/${sessionId}`)
  }
}
```

#### 2. 其他API模块

所有API模块与后端routers严格对齐：

- `query-analyzer.js`: 查询分析API
- `orchestrator.js`: 编排器API（原planner）
- `draft-writer.js`: 内容撰写API
- `reviewer.js`: 质量审核API
- `curriculum-designer.js`: 课程设计API
- `quiz-master.js`: 测验生成API
- `tool-specialist.js`: 工具调用API
- `knowledge-retriever.js`: 知识检索API（对应后端knowledge-manager）
- `socratic-guide.js`: 苏格拉底引导API
- `memory-manager.js`: 记忆管理API
- `system.js`: 系统API（健康检查、统计等）

**API使用建议**:
- ✅ **生产环境**: 优先使用 `workflow` API（完整工作流）
- ⚠️ **数据查询**: 使用 `knowledgeRetriever` 和 `memoryManager` API
- 🔧 **开发调试**: 使用独立的 agent API

### API使用示例

**在组件中使用**:
```javascript
import { useChatStore } from '@/stores/chat'
import api from '@/api'

export default {
  setup() {
    const chatStore = useChatStore()
    
    async function sendMessage() {
      chatStore.setLoading(true)
      
      try {
        const response = await api.workflow.startSession({
          user_id: chatStore.userId,
          query: userInput.value,
          workflow_config: {
            enable_socratic: true
          }
        })
        
        chatStore.addMessage({
          role: 'assistant',
          content: response.response
        })
        
        if (response.socratic_dialogue) {
          chatStore.setSocraticDialogue(response.socratic_dialogue)
        }
      } catch (error) {
        // 错误处理
      } finally {
        chatStore.setLoading(false)
      }
    }
    
    return { sendMessage }
  }
}
```

### 7. 状态持久化

**插件**: `pinia-plugin-persistedstate`

**配置**:
```javascript
// stores/chat.js
export const useChatStore = defineStore('chat', () => {
  // ... state定义
}, {
  persist: {
    key: 'edupilot-chat',
    storage: localStorage,
    paths: ['messages', 'sessionId', 'workflowState', 'socraticDialogue'],
    // 只持久化最近50条消息
    beforeRestore: (ctx) => {
      if (ctx.store.messages && ctx.store.messages.length > 50) {
        ctx.store.messages = ctx.store.messages.slice(-50)
      }
    }
  }
})
```

**优势**:
- 刷新浏览器后自动恢复会话
- 防止未发送的草稿丢失
- 保持苏格拉底教学进度
